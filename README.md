# Mobile Sales Dashboard – Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze mobile sales performance across different cities, brands, mobile models, payment methods and time periods.

## Tools & Technologies

- Power BI
- DAX
- Excel
- Data Visualization
- Time Intelligence

## Dashboard Features

- Total Sales
- Total Quantity
- Total Transactions
- Average Price
- Monthly Sales Analysis
- City-wise Sales Analysis
- Brand-wise Sales Analysis
- Payment Method Analysis
- Mobile Model Analysis
- MTD (Month-to-Date) Analysis
- SPLY (Same Period Last Year) Analysis

## Dashboard Pages

### 1. Main Dashboard

Provides an overview of mobile sales performance using KPI cards, charts, map visualization, payment method analysis and mobile model analysis.

### 2. MTD Analysis

Shows Month-to-Date sales performance using Year, Quarter, Month and Day-level analysis.

### 3. SPLY Analysis

Compares current sales performance with Same Period Last Year across different time periods.

## DAX & Analysis

Created measures for:

- Total Sales
- Total Quantity
- Transactions
- Average Price
- MTD
- SPLY

## Key Insights

- Analyzed sales performance across different months.
- Compared current-period sales with previous-year performance.
- Analyzed sales contribution by brand and mobile model.
- Analyzed transactions across different payment methods.
- Compared sales performance across different cities.

## Project Purpose

This project demonstrates practical skills in Power BI, DAX, time intelligence, data visualization and business-oriented data analysis.
